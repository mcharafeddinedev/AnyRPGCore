## Overview
This is my personal fork of the open-source **AnyRPGCore** framework.  
It includes fixes, configuration updates, and UMA integration adjustments made to ensure full compatibility with **Unity 2021.3.45f2 LTS**.

I’m using this fork for learning, feature development, and as a foundation for my own RPG prototypes and projects.  
The repository tracks my commits, experiments, and technical improvements to the AnyRPG system.

---

## Highlights
- **UMA 2 successfully integrated** and rebuilt for character customization  
- **Full demo scene** running without compile or runtime errors  
- **Compatible with Unity 2021.3.45f2 LTS**  
- Improved import stability, fixed missing references, and setup consistency
- Preserved full AnyRPG + UMA system functionality for modular study and development  

---

## Purpose
This fork serves as both a **technical reference** and a **learning sandbox** for Unity gameplay systems architecture.  
It is designed to help me (and others) explore:
- Framework-level C# design patterns  
- System modularity (Managers, ScriptableObjects, and Events)  
- UI, Player Management, and Game Flow systems  
- Integration of third-party packages (UMA, TextMeshPro, Addressables, etc.)
